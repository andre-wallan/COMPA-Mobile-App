# COMPA — Your Learning Partner

## Overview

COMPA is a React learning app built with Next.js. Students can answer quiz questions, review flashcards, and enter a subject to receive a study suggestion based on their input. The app also generates education-level pages with content tailored to primary school, secondary school, college, and university students.

The project demonstrates interactive React components, form handling, client-side state, and data-driven routes.

## Development Environment

- **Visual Studio Code** — code editor
- **Node.js and npm** — JavaScript runtime and package manager
- **Next.js 16** — React framework using the App Router
- **React 19** — UI library
- **TypeScript** — application language with strict type checking enabled
- **Tailwind CSS 4** — styling


## Features

- **Interactive quiz** — answer questions, see explanations, track your score, and try again
- **Flashcards** — reveal definitions and move through cards
- **Topic-based study suggestion** — enter a subject to display a matching study strategy
- **Education-level pages** — generated from shared data for primary, secondary, college, and university levels
- **Responsive navigation** — move between the landing page, study tools, and learning paths

## How to Run

1. Clone the repository and open its top-level directory.
2. Change to the application directory:

   ```bash
   cd compa
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

To create and run a production build:

```bash
npm run build
npm start
```
